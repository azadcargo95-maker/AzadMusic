# Azad Music (Android)
Offline local music player starter project.

## Build APK
1. Upload this folder to a GitHub repository.
2. Open **Actions** -> **Build Azad Music APK** -> **Run workflow**.
3. When finished, open the workflow run and download the `AzadMusic-debug-apk` artifact. Extract the ZIP to get `app-debug.apk`.

Or build locally with Android Studio (JDK 17, Android SDK 35): open project and Build > Build APK(s).

Features: local audio scan, play/pause, next/previous, shuffle/repeat, seek bar, dark UI.
